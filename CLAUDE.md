# Working in this repo

Start with `docs/code-map.md` instead of reading every file: it lists each file with what it does, who requires whom, and all API routes. Then open only the files the task touches.

- Regenerate it after adding or renaming files or routes: `node scripts/code-map.js`.
- Fair-play detector write-up: `docs/fairplay-detection.md`.
- Tests are `scripts/test-*.js` (run one with `node scripts/test-name.js`); the browser ones need Playwright.
- Keep replies short and token-light.
